# v0.6.0 日常体验增强与审查

日期：2026-11-05。

保留首页、账单、统计三个主页面，加入记账草稿、金额搜索 / 区间筛选、重复点击当前页签回顶部，以及大字体 / 减少透明度适配。账本 schema 仍为 4，金额使用整数分，首次启动仍为空账本。

## 实现与边界

- 草稿：保留最近一个实际修改过的记账表单，包含未完成的计算式、类型、账户、分类、日期、备注和常用项选择。输入停顿 150 ms 后本机保存，进入后台立即尝试刷新；再次点加号直接恢复计算器。仅打开未修改的表单不会覆盖已有草稿。保存成功或主动关闭清除对应草稿，不自动记账。主数据导入、清空、载入示例或恢复快照时清除旧草稿。
- 草稿使用独立 SQLite 表，网页使用独立 localStorage 键，不进入 JSON 备份和本机快照，不改变账本格式。原生账本保存与对应草稿消费在同一事务内；网页不支持跨键事务，以稳定新记录 ID 和编辑来源指纹拒绝已提交的草稿。写入串行化，关闭后不允许延迟保存复活草稿。
- 编辑、退款与周期确认恢复前检查实际记录 / 规则。原记录已删除或修改、账户已移除、周期暂停或推进时，拒绝旧草稿并显示解释；保存时继续执行金额、引用、退款上限和周期唯一性校验。草稿不是系统级备份；突然断电或系统立即杀进程可能丢失最后一次未完成的写入。
- 搜索框可匹配单笔金额，支持 `28.50`、`¥28.50`、`￥28.50`；同时保留备注、分类和账户的文字匹配。组合筛选增加最低 / 最高金额，边界包含，空值不限，允许零下界，拒绝超过两位小数和上下界倒置。按账单原始金额筛选，汇总继续采用原有退款净支出规则，转账不计收支。
- 当前已停稳页签再次点击，立即回顶部；普通切换仍保留滚动位置。账单页回顶部保留搜索、类型与组合条件；首页“查看全部”和“今日支出”的条件规则不变。
- 首页标题可随大字换行，月份与标题在窄屏让位，月份箭头和关闭等图标按钮的实际触摸范围至少 44 pt；dock 可随文字增高。系统减少透明度开启后，dock / 弹层改为实体底色，关闭模糊和渐变取样，仍跟随深浅模式及减少动态效果。

## 审查重点

- 草稿刷新与关闭串行；失败不阻塞下一次写入。草稿自动保存失败可见，财务保存失败保留输入；关闭清理失败时弹层回到屏内并显示重试说明。
- 保存前刷新草稿时立即禁用表单和关闭，避免刷新与取消竞争；稳定记录 ID 避免重试新建产生第二笔。
- 保留计算器有理数计算、退款原始日期归属、转账账户差异、快照失败不覆盖主账本、备份实际 UTF-8 字节检查、应用锁隐藏弹层以及切页缓存。
