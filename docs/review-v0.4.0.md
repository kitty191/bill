# v0.4.0 发布前审查

日期：2026-11-04。

本轮补齐自动本机快照和可选周期账单。主导航保持三页，管理入口在设置，到期才出现首页提示。

## 自动快照与恢复

- 每次有效数据修改前保留完整旧账本，最多 5 个版本；账户显示与提醒总开关不挤占历史。初始空账本也可作为第一份回退版本，未发生修改时不创建数据。
- SQLite 真实 SQL 事务测试覆盖快照 / 主数据原子提交、最终写入失败回滚，以及 v3 升级原始文件随事务回滚 / 重试保留。网页先保存快照，再替换主键；主键失败可能留下一份无害的有效旧快照。
- 快照失败阻止财务覆盖，错误可见。只捕获有效账本，明确恢复损坏主记录时不会把损坏内容伪装成有效快照。
- 列表缓存版本数量计算，所选版本显示收支合计并跟随金额隐藏；导出只包含选中账本，不递归包含快照历史。恢复与清理均二次确认，清理不动当前账本 / 升级备份。
- 恢复在财务队列实际执行时读取快照，验证内容仍与预览一致；无效、消失或变化的版本不得写入。恢复前保存当前有效账本，成功后清除过期删除撤销和快捷修改提示。

## 周期账单

- 默认关闭，无首次示例或自动消费。总开关复用即时反馈与串行后台保存，失败回退。每个规则可暂停，删除规则保留已有账单。
- 到期只预填确认面板，取消不写数据、不推进账期。可改本次金额 / 实际记账日期，规则配置不随本次金额修改；账单保留规则 ID 和原账期，编辑后身份不变。
- 确认账单与推进规则在同一财务更新中保存，任何验证 / 快照 / 主记录写入失败都保留旧账期。重复、未来、暂停、删除或已变化的账期拒绝确认；跳过本期不创建任何账单。
- 周 / 月 / 年均按原始日历基准计算；覆盖月底短月不漂移、闰日、跨年和最终支持年份。导入验证引用、频率、对齐的日期与重复账期。
- schema 4 兼容旧 1 / 2 / 3，保留预算、财务记录、分类和常用项，升级前完整文件单独保留，并优先导出最近一次格式升级前的原始账本。

## 验证与限制

类型检查、180 项单元 / 组件测试、网页生产导出和 46 项交互回归通过。收支预览 / 隐私样式调整后，7 项新增流程另行通过最终页面复查。交互覆盖恢复与逆向恢复、导出文件、清理、损坏主记录 / 快照、保存失败重试、关闭 / 重启、月底跳过、取消预填、确认后编辑和删除规则保留历史。

截图、切页基准、构建与签名结果见 [验证记录](validation.md)。SQLite 测试使用 Node 内置 SQLite 执行相同 SQL，不能代替 Expo 原生桥、真机后台和安装验收；周期提醒为应用内提示。iOS 代码导出不等于可安装 IPA。
