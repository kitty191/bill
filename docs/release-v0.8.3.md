# 清账新版 v0.8.3

- 账单页支持多选同类收支后统一分类。支出关联的退款同步调整，转账保留原分类。
- 设置可下载清账 CSV 模板并预览导入。收入、支出和转账使用已有账户与分类。有效记录确认后追加，疑似重复及无效记录会列出并跳过。关联退款适合用完整 JSON 迁移。
- 月度回顾列出净支出的环比差额及前三个变化分类，可跳到对应月份的账单。
- 分类预算是每月重复的分类额度，首页提示接近上限和超额。每月总预算可独立设置。
- Android 桌面长按图标可选「记支出」或「记收入」。应用锁及未完成草稿仍按原流程处理。
- 最近一份自动备份支持只读回读校验，显示可恢复账单数。
- 手动备份可选密码加密。加密格式使用 PBKDF2-HMAC-SHA-256（600,000 次、随机盐）和 AES-256-GCM。加密导出支持小于 48 MB 的账本。自动备份继续使用普通 JSON，恢复入口支持两种文件。

Android 包名与此前分发的清账新版一致。打包、签名检查及真机升级步骤见[清账新版 Android 更新](android-update.md)。
