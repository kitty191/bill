# v0.3.3 发布前审查

日期：2026-11-04。

本轮先完成今日明细与记账后快捷修改，保持三个主页面，不新增设置入口。自动备份快照与周期账单暂留后续。

## 今日明细

- 首页「今日支出」变为有箭头的可点击行，按点击时的本地日期进入账单页；即使正在查看其他月份，也会定位当前月份、重置列表位置。
- 重置旧搜索、日期、分类、账户和类型条件，应用当天日期与支出类型。合计沿用原消费日退款抵扣，和首页净支出一致；有退款时补充「原支出 / 已退」，解释明细原始金额与净合计。
- 普通切页保留筛选；再次点击今日入口重新定位，首页「查看全部」清除全部条件。当天没有支出时可记下今天第一笔。
- 可访问按钮标签与退款说明均使用隐藏金额后的显示值，不泄露实际金额。跨年零点后的点击读取新日期。

## 快捷修改

- 只有持久化成功才把实际保存 ID 交给提示，保留 8 秒「修改」。新建、收入、转账、退款与编辑共用保存流程，失败保留输入。
- 点击时从当前账本按 ID 取记录，重新检查期限，不使用旧的表单快照；编辑保持原 ID 与创建时间。删除后的提示没有修改入口。
- 连续成功保存即使提示文字相同，也以新的提示对象重置期限；旧超时回调不能清除新提示。过期及重启后入口消失。
- 快捷修改与已有删除撤销可同时显示。打开编辑时隐藏提示面板，关闭后保留仍有效的撤销；不改变删除保护、8 秒期限和串行财务写入。

## 验证与限制

类型检查、141 项单元 / 组件测试和网页生产导出通过。新增组件测试核对失败不回调成功、重试后使用真实保存 ID；交互回归核对日期 / 类型 / 账户 / 分类 / 搜索重置、月份独立、重复进入、隐私、连续保存、修改身份不变、8 秒过期、重载和删除撤销共存。

窄屏浅色 / 深色实际截图、完整交互和切页基准结果见 [验证记录](validation.md)。测试使用生成账本，未上传私人录屏。云端结果不代替原生真机的触摸、系统返回、后台唤醒和安装验收；iOS 代码导出不等于可安装 IPA。
