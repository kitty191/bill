# v0.8.0 审查

日期：2026-11-06（Asia/Shanghai）。范围为 Android 后台文件备份、原签名一键发布及回归发现的网页快速切页问题。账本 schema 仍为 4，原签名保留。

- 后台备份需单独开启，旧配置默认关闭；复用完整 JSON 验证、七份有效版本与可见错误。首次后台执行生成首份副本，之后按到期频率执行；最近后台成功时间独立记录。关闭频率同时关闭后台开关，残留已排队任务也会检查配置。
- 前台 / 手动 / 后台统一读取磁盘中的最新已提交账本，租约放在独立 SQLite 数据库，写入、读取、清理与更新配置前验证所有权。过期拥有者无法删除新任务租约或覆盖新设置；未完成文件不能挤掉有效版本。
- 系统任务在模块初始化阶段定义，支持缓存进程回收后的无界面加载。默认每小时由系统检查是否到期；Android 省电 / 网络状态可能延迟执行，系统强行停止后需重开。后台读取不经过界面应用锁，导出文件不加密；iOS / 网页保持前台备份。
- 发布脚本真实执行检查、原签名构建和校验、提交推送、创建预览 Release 和匿名下载核验。强制验证版本递增、原证书、Release / ARM64、字节数、SHA-256、CRC、16 KB 对齐、内置模块与计数器缺席；没有匹配 Android 应用 / 构建输入的原生成功验收就停止。它不向 GitHub 上传私钥，尚未启用常驻无人值守签名服务。
- 完整浏览器检查发现一次快速触摸甩动越过两页。网页改为单一吸附目标，并将触摸惯性限制在起始页相邻一页；dock 点击 / 尺寸变化可立即解除约束。修复后的同一图表取消与快速切页用例连续 10 次通过，没有放宽断言；手机端仍使用独立原生分页。
