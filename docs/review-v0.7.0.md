# v0.7.0 审查与验证

日期：2026-11-05（Asia/Shanghai）。范围：原生性能与启动准备、键盘弹层、异常保存、覆盖升级、自动文件备份、自动测试和 Android 构建。账本 schema 保持 4。

## 实现与边界

- 首页与月统计使用缓存结果，首页呈现后再初始化统计；SQLite / 网页持久化层返回严格校验后的规范账本，提供者不重复校验。未改变整数分、退款、转账或迁移规则。
- Android 弹层避让键盘并将聚焦输入滚入可见区域，返回优先收键盘。长按真实触摸测试发现释放事件误点新菜单，已用仅覆盖当前手势的网页事件防护修复；新的点击和键盘输入立即解除防护。网页快速滑动增加每页吸附，原生分页仍沿用原组件。
- 自动文件备份默认关闭，用户指定目录和 1 / 7 / 30 天频率；只在解锁的应用前台到期检查。文件成功回读后才登记完成，然后保留本安装最近 7 个有效版本。不包含草稿、隐私设置和备份配置，不自动上传。写入失败不清理旧版本，不阻塞记账。iOS 可能需要重新选择目录，卸载前仍需确认独立文件可用。
- 快照 / 账本 / 草稿在事务中一致保存。增加真实 SQLite WAL 子进程写入中 SIGKILL 测试，以及草稿删除失败的整事务回滚 / 重试测试。异常输入在写入前严格拒绝。
- GitHub Actions 自动执行浏览器回归与 Android 测试签名构建；原生流程和真实设备的区别见 [原生验收](native-validation.md)。

## 性能解释

[三组配对 Chromium 数据](performance-comparison-v0.7.0.json) 使用同一台云机器、一万条生成账单与相同测量脚本，先后交替运行旧版和候选版。结果波动明显，候选版没有显示稳定的启动、搜索或保存提速，不能宣传百分比性能提升，更不能据此声称原生 60 / 120 Hz。

现有原生分页 UI 线程动画未改；本轮保留可独立审查的缓存与重复校验减少，并增加实际设备采集入口。真机冷启动、帧率、中文键盘、iOS 目录授权和触感仍待安装验收；本轮发布为 Android 预览版。
