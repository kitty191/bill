# v0.6.1 月份与记账便捷操作审查

日期：2026-11-05。

本轮保持三个主页面，在现有控件中补齐月份快速跳转、草稿重新开始和明确的金额筛选摘要。账本 schema 仍为 4，财务金额与退款 / 转账规则不变。

## 改动

- 点击首页、账单或统计中的月份，输入四位年份并点击月份即可跳转；保留前后月箭头，提供返回本月。支持 1900 年 1 月至 2200 年 12 月，边界箭头禁用，年份未填完整或越界时禁止选择。关闭选择器不改变当前月份，也不写入账本。
- 设置中的预算月份复用同一控件，独立于浏览月份；跳转只预览该月预算，点击保存预算才持久化。选择月份防止重复回调导致跨年偏移累加。
- 恢复草稿后，提示旁提供“重新记”。成功清除旧草稿后，在同一个计算器 / 弹层中切换为全新支出表单：金额、备注和常用项选项清空，日期为今天，分类和账户沿用新建默认值。新表单使用新记录 ID，从编辑、退款或周期确认恢复的草稿重新开始，也不会修改原记录、保留退款关联或推进周期。
- 草稿清理失败时不丢弃输入、不切换表单，显示错误并支持重试。新空白表单不主动保存为草稿；继续输入后重新启用自动保存，退出恢复使用新身份。
- 金额筛选摘要显示 `¥20–100`、`≥¥50`、`≤¥100` 或精确金额 `¥20.50`；区间边界包含，保留分的精度，隐藏金额时只显示“金额条件”。原有日期、分类、账户与类型组合继续生效。

## 审查与保护

- 修复异步清理期间重复关闭可提前离开表单的问题。只有财务提交完成后允许保存退出回调直接关闭，草稿取消中的重复回调等待清理；减少动态效果下也先设置关闭标记，防止重复触发。
- 重新开始只清除当前草稿；不会写入财务记录、删除历史账单、修改预算或推进周期。切换身份后重建草稿基线，保持新建空表单不覆盖其他未完成输入的规则，并清除旧的草稿保存错误提示。
- 数值摘要从整数分生成，不参与统计计算；年份 / 月份校验在跳转入口执行。没有增加权限、网络上传、账户注册或新的主导航。
