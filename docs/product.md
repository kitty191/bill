# 产品与设计决策

## 目标

做一款同时支持 iOS / Android 的个人记账 App。极简、清爽，具有 iOS 风格的玻璃材质、丝滑且自然连贯的过渡。使用者负责后期审查，日常实现选择由 Codex 自主推进。

暂定名「清账」，默认中文、人民币、本地优先。主导航只放首页、账单、统计；记一笔为独立常驻入口。账户、预算、备份放在设置中。

## 视觉

- 暖白画布、森林绿文字、薄荷绿强调。浅色与深色分别定义色板。
- 收支数字是视觉中心。正文稳定，玻璃仅用于浮动导航，避免多层透明面板造成噪声。
- 系统字体、充足留白、轻边界。类别颜色仅辅助识别。
- Android 使用轻量半透明底色、渐变和边缘高光形成玻璃观感，避免在滑动时对整块页面实时模糊取样。iOS 保留原生模糊。

## 动效

- 页面与 dock 按首页、账单、统计从左到右排列；手指左滑进入右侧页面，右滑返回。点击右侧按钮时，右侧页面从右侧进入；滑块、图标和文字高亮随实际页面位置变化，快速改选可以中断正在进行的切页。
- 手机端使用 ViewPager2 / UIPageViewController，拖动、速度与吸附由原生组件处理；动画进度在 UI 线程更新，React 在页面停稳后同步状态。各页内容与回调保持稳定，滑动不触发三页账单重新渲染。
- 各页保留纵向滚动位置；首页账户卡片的横向滚动独立于切页。账单筛选在普通切页时保留，从首页「查看全部」进入时重置。
- 记账按钮按压后轻微缩放、回弹；手机上尝试轻触反馈，能力缺失不阻塞操作。
- 面板短距离淡入、拖动跟手，下拉可关闭，未达阈值时回弹。
- 跟随系统减少动态效果设置。后续以两端真机的帧率、手势和键盘表现校准。

## 当前范围

先把手动记账、账户、转账、统计、预算、备份恢复做成完整闭环。首次空账本，不把示例数据混入真实记录。金额用整数分，导入严格验证，财务数据持久化成功后才更新；显示开关先响应操作，后台保存失败则回退并提示。

暂缓登录、云同步、家庭账本、OCR、自动导入、复杂预算和多币种，待核心体验通过审查后按需求扩展。

首页账户卡片（微信、支付宝、银行卡、现金等）与总资产默认隐藏。设置中提供「首页显示账户卡片」开关，保存后立即生效并在重启后保留。关闭时不删除账户或账单，账户管理和记账继续可用。示例载入和清空账本保留显示选择；备份恢复使用备份内的选择，旧备份缺省关闭。

每日支出使用折线与浅色面积填充，轻触查看日期与金额。按日累计整数分，排除收入和转账，缺少支出的日期补零；历史月份显示完整日历，当前月份显示到今天或已有的未来记录日期，避免将尚未发生的日期画成零支出。使用直线连接实际日值，避免曲线插值造成金额越界；单日和全零数据也可显示。

## v0.2 日常记账增强

保持三个主页面；分类、常用项和隐私设置集中到设置子页面。首页仅在存在常用项时显示快捷入口，提醒到期后才出现备份卡片。

- 快捷记账：按支出 / 收入分别记住最近一次新建时的分类和账户，金额仍留空。常用项保存名称、金额、分类、账户和备注，点击后预填，确认才产生账单。最多 30 项，隐藏分类的常用项保留但不出现在快捷入口。
- 分类：新增、重命名、选择图标与颜色、上下调整顺序、隐藏。隐藏只影响新建可选项，已有账单仍可查看编辑，每种收支至少一个可用分类。
- 退款：从原支出发起并保留关联，可多次部分退回，累计不超过原金额，退款日期不能早于原支出。统计按原支出日期计算净支出，余额按实际到账账户计算；不冒充收入。有退款时不可直接删除原支出或改为收入，需先删除关联退款。
- 年度：月 / 年切换放在统计页，展示 12 个月收入与净支出、全年结余、月均及分类同比。历史年按 12 个月，当前年按截至当前月或最后记录月份，未来年按已记录月份；上年同期比较采用相同月份范围。
- 隐私：金额隐藏覆盖列表、账户、统计和可访问金额文本，编辑输入与导出保留实际值。应用锁使用操作系统的强生物识别及设备凭据回退，开启需已录入指纹 / 面容并验证；每次进入后台后锁定，下次前台验证，取消仍锁定。锁定保留未提交的编辑状态，同时隐藏面板。设备隐私偏好不进入账本备份，应用锁不等于数据加密。
- 备份：可选每周 / 每月应用内提醒，默认关闭，可延后一天。生成 JSON 后记录导出时间，提示确认文件已保存；没有系统通知或云端自动上传。schema 1 升级为 2，首次写入前原样保存旧快照；保存快照失败则不覆盖原账本。

## v0.3 记账和查账工具

- v0.3.1 起点加号直接显示金额和计算键盘，支持加减乘除、括号和小数，最终结果四舍五入到分。金额 / 算式共用一份草稿，点等号只显示结果，固定在底部的「记好了」可直接计算并保存，无需额外确认计算结果。常用项和编辑账单的预填金额，首次按数字替换原值，按运算符则继续计算；应用锁隐藏 / 重建面板后仍保留草稿。
- 日期保留直接输入，并提供日历、今天和昨天。金额下方的分类 / 账户 / 日期摘要可直接跳到详情，展开日历后自动滚入视野；筛选开始 / 结束日历互斥。关闭或拖动面板时收起系统键盘，跟随减少动态效果。
- 账单支持可组合的日期范围、分类、账户、类型及关键词。日期包含起止两天，转账匹配转出或转入账户；汇总使用筛选结果，退款仍抵减原支出期间，另显示筛选中的实际退款到账额。隐藏分类仍可检索。按日一次分组，避免长范围反复遍历。
- 按月预算写入 `monthBudgets`，每月独立修改。schema 1 / 2 的旧共享预算作为未覆盖月份的默认值保留，0 明确关闭选定月份；新账本各月默认未设置。首次 schema 3 写入前原样保留旧账本，备份与写入在 SQLite 同一事务中完成，网页先保存快照再替换主数据。
- 单笔删除仍先确认，成功后提供 8 秒撤销，只保留最近一笔。撤销在当前账本上重新校验日期、账户、分类与退款关联，不覆盖同 ID 记录；失败保留已提交数据。批量清空、示例载入与备份恢复清除撤销，超时不得重新写回。

## v0.3.2 今日支出

- 首页月支出数字下方增加一行「今日支出」，按手机本地日期筛选账单，独立于当前查看的月份。不计收入和转账；沿用已有净支出口径，退款抵扣原消费日，昨天消费的退款不影响今天的消费合计。
- 持续打开时在本地午夜切换日期，后台返回时立即刷新；前台校正检查兼容修改时钟 / 时区及夏令时。仅日期变化时更新页面状态，同日检查不触发 React 重渲染，后台暂停检查。
- 只切换统计日期，不删除账单或写入「清零」记录。若提前录入了新一天的消费，到该日显示对应合计。新建、修改、删除和退款提交后即时更新，跟随隐藏金额偏好。
