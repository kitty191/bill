# v0.3.1 发布前审查

日期：2026-11-04。

点加号直接显示金额和计算键盘，移除「打开计算器」和计算结果填回金额的额外步骤。保存按钮固定在底部，输入金额或算式后可直接保存。

## 金额与保存

- 只有一份由表单持有的金额草稿；计算键、手工输入、预览、等号和保存都使用同一表达式，避免保存旧金额。等号不写入账本，保存可直接计算表达式。
- 继续使用精确有理数计算，最后四舍五入到分；空值、除零、非正金额和越界值拒绝保存。持久化成功后才关闭表单和提示成功。
- 常用项或旧账单首次按数字替换预填值，按运算符则继续计算；等号后的数字开始新金额，运算符继续使用结果。重复小数点、无匹配右括号、未知按键及过长输入受到限制。
- 草稿含表达式、结果替换状态和错误，保存在表单层；应用锁隐藏并卸载原生面板后，输入和继续计算的状态仍保留。
- 分类、账户、日期、备注、常用项、退款和删除流程继续保留；日期展开自动进入视野。金额下的摘要可跳到详情。
