# v0.5.0 发布前审查

日期：2026-11-04。

本轮落实排版、玻璃材质、动效触感、图表探索和复制账单五项调整，保持首页、账单、统计三个主页面。

## 视觉与交互

- 统一 MoneyText：主金额突出，小数与币种降低字号，数字使用等宽数字特性。首页、账单汇总、统计与年度汇总、记录行使用同一规则；仍沿用整数分及金额隐藏，完整文本与可访问金额保持一致。
- 浅色正文卡片使用白色实体表面、轻边界与薄阴影；深色按独立配色校准层次。首页收支卡保留柔和渐变。玻璃集中在浮动 dock 和弹层，以渐变、高光边缘、深浅色独立的透明底色和阴影区分层次。
- iOS / 网页使用 BlurView；Android 延续轻量渐变材质，不新增实时背景模糊。此实现不是系统 Liquid Glass 的真实折射，视觉与能耗仍需真机审查。
- 按钮按压在 UI 线程轻微缩放，松开可中断地回弹；统一按压、淡入、退出和弹簧参数。关键切换、打开、选图、保存成功与失败提供适量触感，能力缺失不影响财务操作；网页不触发设备触感。
- 弹层背景与面板分别进入，下拉时背景跟随变淡；支持反向拖回和取消回弹。拖动按实际面板高度判断，修正偏高的关闭阈值；原生拖动留在 UI 线程。保存成功后通过同一退出动作收起，重复点击在操作开始时拦截，退出期间继续禁用操作。
- 减少动态效果时取消缩放 / 自动过渡和回弹，保留即时状态反馈与用户直接拖动。
- 小图标按钮保留额外触摸范围，视觉尺寸保持轻巧；最后调整后，类型检查、网页导出及两项图表 / 窄屏关闭流程再次通过。

## 图表探索

- 日 / 年折线图共享横向拖动、轻触和可访问增减操作，网页支持方向键、Home、End；年度只选择实际观察到的月份。
- 只识别横向探索，纵向手势交还页面滚动；开始探索时锁住横向分页，失败、结束、取消和卸载时释放，防止图表拖动切换页面。
- 日图增加选择点、竖线与金额浮层；浮层限制在图表左右边界，根据手指所在的上下半区切换位置。读数仍按实际每日净支出，不做曲线插值或改统计口径。
- 金额隐藏同时覆盖轴标签、最高金额、浮层、下方读数及可访问文本；键盘焦点采用主题色提示。

## 再记一笔

- 首页 / 账单列表长按打开快捷操作，可编辑或再记一笔；正常点击仍打开详情，详情也有「再记一笔」入口，供不方便长按的用户使用。
- 预填原金额、类型、分类、付款及转入账户、备注，日期使用打开时的本地今天。取消或打开菜单不写账本，确认后才生成新 ID 和创建时间，原记录保持不变。
- 复制周期历史不继承原账期标记，不推进周期规则；复制转账仍不计收支。复制退款保留原支出关联并重新验证剩余可退金额，不允许超退。
- 原记录有未保存修改时提示先保存，避免丢失编辑。保存失败保留预填 / 修改内容，原账本不变，可重试；快速重复保存不会产生两条记录。
- schema 仍为 4，现有 SQLite / 网页快照、恢复、预算、撤销、隐私、计算键盘与分类逻辑继续使用原有校验与事务。

## 验证

- 类型检查、187 项单元 / 组件测试通过，新增直接覆盖持久化前和退出期间连续保存只入账一次。
- 完整 54 项 Chromium 回归，以及 2 项额外图表 / 窄屏隐私交互检查通过，覆盖所有原有财务流程与本轮新增行为。网页检查不能代替原生桥、系统键盘、触感和安装验收。
- 新流程核对复制支出 / 收入 / 转账 / 退款、取消无写入、原记录与 ID 保留、今日日期、周期标记隔离、超退拒绝、失败重试、未保存编辑保护；图表核对横向选点、纵向滚动、取消后分页恢复、键盘边界、隐私和浮层位置；弹层核对正常动画下反向拖动保留算式及明确下拉关闭。
- 切页 / 大账本测量、生成账本截图、平台导出和 APK 校验结果见 [验证记录](validation.md)。手机帧率、玻璃效果、动态字体、触感及原生手势还需真机验收；iOS 代码导出不等于可安装 IPA。
