清账 v0.8.1 整理了账户管理、日期筛选和备份恢复体验。

- 停用账户可归档并恢复。归档后从首页卡片和新记账、转账选项收起，历史账单仍可筛选和编辑，余额仍计入总资产。使用关联常用项或周期账单时，可以手动选择另一个可用账户。
- 组合筛选新增「近 7 天」和「上月」。日期可以继续调整，并与分类、账户和金额条件一起使用。
- 手机手动导出会等待文件写入完成再打开分享。恢复本机快照后，设置页同步显示恢复的预算。历史日期校验在切换设备时区后仍使用相同的日历规则。
- 网页保存失败时会保留未保存的草稿，清空输入后不会在重开时恢复旧金额。网页筛选弹层滚动时保留输入焦点。

该版本面向 Android ARM64，最低 Android 7.0。应用包名为 `com.kitty191.qingzhang`，账本格式继续使用 schema 4。
