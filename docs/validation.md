七个端到端场景：

1. 收入、支出、转账、修改、删除、搜索与重载；检查月度金额，转账不改变收支。
2. 预算、账户初始余额、示例账本；导出并读取 JSON / CSV 内容。
3. 无效金额、写入失败；表单保留且已保存数据不变。
4. 拒绝无效备份；合法备份在确认前不覆盖，确认后替换。
5. 修改日期后账单移入正确月份。
6. 损坏的本地数据不会被空账本覆盖，可选择有效备份并确认恢复。
7. 320 像素窄屏、深色、减少动态效果模式；记账和导航可操作。
