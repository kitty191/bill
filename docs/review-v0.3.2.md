# v0.3.2 发布前审查

日期：2026-11-04。

首页月支出下方增加「今日支出」，沿用现有大卡片，避免增加页面层级。

## 统计与日期

- 按手机本地日期匹配账单日期，独立于当前查看的月份；只计算支出，收入和转账不计入。沿用已有净支出口径，退款抵扣原消费日，不把昨天消费的退款算成今天的负支出。
- 金额直接从已提交账本推导，保持整数分计算，跟随隐藏金额偏好。未新增持久化字段，也没有午夜删除历史或写入清零记录；新日期若已有提前录入的账单，显示其实际合计。
- 本地午夜定时刷新，后台返回立即校正。使用本地日历计算下一个午夜，兼容夏令时；前台最长每分钟校正系统时间变化，日期相同不触发 React 更新，后台停止定时检查。
- 本地日期由主界面统一提供，切页缓存仍保持稳定，相对日期和统计图也会同步进入新一天。清理定时器及 AppState 订阅，避免卸载后继续检查。

## 验证与限制

- 类型检查、140 项单元 / 组件测试、网页生产导出通过。9 项日期生命周期用例另外在 `America/New_York` 时区复测，覆盖 23 / 25 小时夏令时日、跨年、闰日、午间不重置、同日不重渲染、后台返回、前后调整时钟与卸载清理。
- 原有 34 项交互回归通过，新增 2 项覆盖消费日期与退款口径、月份独立、隐私持久化、本地跨年零点刷新、历史原始数据不变、新日期记账及重载。
- 已查看 320px 浅色 / 深色实际截图，见 `docs/previews/today-v0.3.2-light.png` 和 `today-v0.3.2-dark.png`，使用生成的测试账本。
- 1000 条账单连续切页 9 次，三个页面均 0 次重复渲染，无运行错误；见 `docs/paging-performance-v0.3.2.json`。该结果不等于原生帧率测量。

构建和签名记录见 [验证记录](validation.md)。云端未进行真机安装、后台唤醒、系统时区设置及触摸体验验收；iOS 代码导出不等于可安装 IPA。
