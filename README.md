# 清账

简单记录，轻盈生活。一款面向 iOS 和 Android 的极简个人记账应用，采用暖白 / 深绿底色、克制的磨砂玻璃与连贯动效。

目前为可审查的 **v0.6 本地账本预览版**。首次打开为空账本，可以在设置中明确选择载入示例。无需注册，不接入广告、分析 SDK 或云端账户。

## 已实现

- 首页：今日支出、按月收支、结余、预算进度、最近记录。今日支出按本地日期统计，午夜自动切换，后台返回时同步刷新；点击可查看当天支出明细。账户卡片与总资产默认隐藏，可在设置 → 首页显示 → 首页显示账户卡片中打开或关闭，选择会保存。
- 切页：页面与 dock 按首页、账单、统计从左到右排列；手指左滑进入右侧页面，右滑返回。滑块、图标和文字高亮跟随实际页面位置。各页保留滚动位置，再次点击当前页签回顶部并保留账单筛选，账户横向滚动独立处理。点击月份可输入年份并选择月份，或返回本月；预算月份独立选择。
- 记账：支出、收入、账户转账；点加号直接显示数字 / 计算键盘，支持加减乘除和括号，点「记好了」直接计算并保存；成功后 8 秒内可点提示中的「修改」直接编辑刚保存的一笔。长按账单或在详情点「再记一笔」，沿用内容、日期默认今天，确认后保存为新记录。分类、日历 / 今天 / 昨天选日期、备注；编辑、二次确认删除、最近一笔删除的 8 秒撤销。新建时记住上次支出 / 收入的分类与账户；可存为常用项，从首页预填后确认记账。
- 草稿：输入后自动保存本机未完成表单，意外退出后点加号继续；保留未完成的计算式与备注。保存或主动关闭清除对应草稿，恢复前校验原账单，不自动记账，草稿不进入备份。恢复后可点“重新记”，在当前计算器开始全新记录。
- 分类：在设置中新增、重命名、调整顺序或隐藏，历史账单与统计保留；每种收支至少保留一个可用分类。
- 退款：打开原支出后选择「记录退款」，支持多次部分退款。累计不能超过原金额；退款减少原支出期间的净支出、增加到账账户余额，不计作收入。
- 账单：月份切换、类型筛选、备注 / 分类 / 账户 / 单笔金额搜索；组合日期范围、分类、账户与金额区间筛选，摘要显示具体上下界，隐藏金额时同步隐藏数值；汇总随结果变化，转账可按转入账户查询；按日分组、按需渲染，搜索复用索引，完整结果仍参与合计。
- 统计：支出分类占比与排行、每日支出折线图、上月对比。轻触或横向拖动折线查看当天金额，浮层避开手指并限制在图表边界，缺少支出的日期按零显示；收入和转账不计入曲线；退款抵减原支出日。另有全年收支折线、月均净支出及上年同期分类对比。
- 设置：账户名称与初始余额、添加账户、各个月份独立预算；分类、常用项与隐私偏好放在子页面中。
- 隐私：一键隐藏显示金额；手机独立安装版可开启系统指纹 / Face ID 应用锁。可选每周 / 每月备份提醒，到期在首页提示，默认关闭。
- 数据：完整 JSON 备份与恢复、CSV 导出；自动保留最近 5 个修改前的有效账本快照，可预览、导出或确认恢复；损坏主账本也能从本机快照恢复。存储失败保留输入，快照失败不覆盖账本。快照不随 JSON 递归导出，换机前仍需备份。
- 周期账单：默认关闭，在设置中管理每周 / 每月 / 每年的房租、会员或工资提醒。到期在首页预填，确认后才记账，也可跳过或暂停；月底、闰年保持原日期基准。同一期不能重复确认，提醒为应用内提示。
- 外观：跟随系统深浅模式，主金额、小数和币种分级排版；底部 dock 与弹层统一磨砂、渐变、高光和边缘阴影，正文使用清晰的实体卡片。按钮轻压回弹，弹层支持跟手下拉 / 反向拖回，保存后自然退出，适配大字体和系统减少动态效果；减少透明度开启时，dock / 弹层使用清晰实体底色并关闭模糊。
- 滑动性能：手机端采用原生分页，动画进度在 UI 线程更新；缓存页面与回调，避免切页时重算全部账单。Android 使用轻量半透明玻璃材质，iOS 保留原生模糊。

## 开发

需要 Node.js 24（至少 24.3，当前验证版本 24.19）、npm 11。使用已有检出目录，无需额外 worktree。

```sh
cd /workspace/bill
npm ci
npm run web
```

手机开发：在可以连接手机的开发机器上检出仓库，执行 `npm ci` 和 `npm start`，使用支持 Expo SDK 58 的 Expo Go 或开发构建。iOS 模拟器需要 macOS / Xcode，Android 模拟器需要 Android SDK；云端的网页检查不代表原生真机验证。

当前技术栈：Expo SDK 58、React Native 0.88、React 19.3、TypeScript 6、Reanimated 4、SQLite。版本以 `package-lock.json` 为准。

Android 预览版：[下载 v0.6.1 APK](https://github.com/kitty191/bill/raw/refs/heads/main/downloads/qingzhang-v0.6.1-android-arm64.apk)，约 31 MB，支持 ARM64 系统的 Android 7.0 及以上手机，内含应用代码，无需 Expo Go 或开发服务器。本轮加入点击月份直接跨年跳转、恢复草稿后在当前计算器重新记账，以及具体金额范围摘要；保留现有玻璃材质、动效、图表和财务规则。沿用原签名，可直接覆盖安装旧版并保留账本。安装包校验与真机验收范围详见 [下载说明](downloads/README.md)。

独立 APK 构建入口为 `npm run build:apk`，工具链、私有签名配置和网络前提见 [Android 构建说明](docs/android-build.md)。IPA 尚未生成，另需 macOS / 远程构建服务及 Apple 签名。

受限网络下，Metro 可以使用 `EXPO_OFFLINE=1 npm run web -- --localhost`。如需安装 SDK 模块，使用 SDK 自带映射：`EXPO_OFFLINE=1 npx expo install <模块>`；npm 仍需访问官方包仓库，不关闭 TLS 或完整性校验。

## 验证

```sh
npm run typecheck
npm test
npm run export:web -- --max-workers 2
npm run test:e2e
npm run benchmark:paging
```

端到端测试使用 Chromium，默认路径 `/usr/bin/chromium`，可通过 `CHROMIUM_PATH` 指定浏览器可执行文件。测试自动启动本机静态服务器；先执行网页导出。测试覆盖真实的新增、转账、编辑、删除、重载、预算、账户管理、导出、恢复、存储失败、窄屏深色流程，以及触摸切页、首尾边界、嵌套滚动和折线图点选；新增分类 / 常用项管理、退款、年度统计、金额隐藏、备份提醒和升级快照检查。

切页基准使用 1000 条模拟账单，检查 9 次切页期间静态页面的渲染次数，结果默认写入 `/tmp/qingzhang-paging-benchmark.json`。它会短暂插入计数代码并恢复源文件，请勿与源文件编辑并行运行；该基准不测量原生设备帧率。

大账本基准：先导出网页，再执行 `node scripts/benchmark-ledger.cjs dist /tmp/qingzhang-ledger-benchmark.json --check`。使用一万条生成账单检查挂载行数、搜索、清除搜索与保存完整性。网页单次对比和 SQLite 写入量见 [v0.4.1 审查](docs/review-v0.4.1.md)，不能当作手机帧率或原生保存耗时。

原生 JavaScript / 资源导出：

```sh
EXPO_OFFLINE=1 npx expo export --platform ios --platform android --output-dir /tmp/qingzhang-native --max-workers 2
```

这能验证两个原生平台的模块与打包，不能代替生成安装包、SQLite 原生运行、真机触感、键盘、玻璃效果和帧率测试。

## 数据说明

- 所有金额使用整数分计算；当前单笔上限 ¥9,999,999.99，仅支持人民币。计算器使用有理数精确运算，仅在最终结果四舍五入到分；除零、非正结果和超出上限会拒绝。
- 账户余额 = 初始余额 + 全部账单变动；支持负余额。初始余额和账户转账都不计入收支。
- 手机使用 SQLite 单行 JSON 保存当前账本，最近 5 个自动快照分别存行；新增快照、裁剪历史、升级前备份与主账本写入在同一事务中完成。v0.4.0 的快照在首次需要写入时原子迁移，保留原 ID、时间和顺序。网页使用当前浏览器的 `localStorage`，适合原型审查，按单窗口使用。
- schema 版本为 4，可读取 schema 1 / 2 / 3。升级保留财务记录、预算、分类和常用项，周期提醒默认关闭；`monthBudgets` 的旧预算兼容行为不变。首次 schema 4 写入前保留完整原始文件，设置可导出，此前快照仍保留。未知版本拒绝覆盖，旧版应用不能读取新版备份。清空账本保留本机隐私偏好、升级前备份和自动快照。
- 隐私偏好仅保存在本机：手机使用 SecureStore，网页为独立 localStorage 键，不随账本导出或恢复。应用锁是访问验证，不会加密账本或导出的文件；系统生物识别失败或取消时保持锁定，可使用系统提供的设备凭据回退。网页不能启用应用锁；Face ID 需独立 iOS 构建。
- 备份提醒只在应用内显示，不发送系统通知，不自动上传。JSON 文件生成后记录导出时间；系统分享面板不能确认是否已保存，请自行确认，CSV 不重置提醒。
- 数据保存在本机，尚未实现额外的应用层加密、云同步和自动备份。卸载 / 清除应用数据可能丢失账本，请定期导出 JSON。CSV 用于查看，不用于恢复。
- JSON 备份包含全部财务数据和按月预算，文件上限为 64 MB，导入与导出均检查实际 UTF-8 字节数；兼容文件开头的 UTF-8 标记，仍严格验证账本内容。请妥善保管，恢复会替换当前账本，应用内需再次确认。撤销仅针对最近一次单笔删除，8 秒有效；清空、示例载入或恢复备份会清除撤销状态。
